# InvoiceFlow - Smart Automated Invoicing & Payout Dashboard

An AI-ready invoicing, billing, and instant payout management platform for freelancers and modern agencies.

## Features
- ⚡ **Instant Stripe Payouts**: Real-time disbursement integration and balance management.
- 🎨 **Premium Glassmorphic UI**: 3D mascot hero interactions, curtain page transitions, and smooth physics.
- 🔐 **Authentication**: Powered by **Better Auth** with Email/Password & Social OAuth (Google, GitHub, Facebook, LinkedIn).
- 📊 **Dynamic Analytics**: Live invoice status tracking, multi-currency revenue visualization, and real-time math.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
